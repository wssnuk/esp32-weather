# 🌤️ ESP32 Weather Monitor — จอแสดงสภาพอากาศปัจจุบัน

สำหรับบอร์ด **ESP32-2432S028 (Cheap Yellow Display)** ที่มีจอสัมผัส 2.8 นิ้ว (ทั้งรุ่น USB ช่องเดียวและรุ่น micro-USB + USB-C)

บอร์ดดึงข้อมูลสภาพอากาศจริงผ่าน Wi-Fi ทุก 10 นาที จาก Open-Meteo ที่ใช้ฟรี ไม่ต้องสมัคร แล้วแสดงผลได้ 3 ทาง
1. **จอบนบอร์ด** แสดงไอคอน อุณหภูมิ คำอธิบายภาษาไทย และนาฬิกา (ดูตัวอย่างใน `screen-preview.png`)
2. **หน้าเว็บบนมือถือ/คอม** เปิดที่ `http://esp32-weather.local` หรือเลข IP ของบอร์ด
3. **Serial Monitor** รายงานเป็นตัวหนังสือ

ข้อมูลที่แสดง: สภาพอากาศ, อุณหภูมิ, อุณหภูมิที่รู้สึกได้, สูงสุด/ต่ำสุดของวัน, ความชื้น, ฝน, โอกาสฝน, ลมและทิศลม, ค่า UV, เวลาพระอาทิตย์ขึ้น/ตก

> วิธีด้านล่างเป็นวิธีติดตั้งเองด้วย esptool-js (ใช้ไฟล์ `docs/firmware/esp32-weather-full.bin`)

## ขั้นที่ 1 — ติดตั้งเฟิร์มแวร์ลงบอร์ด (วิธีสำรอง)

สิ่งที่ต้องมี: คอมพิวเตอร์ที่มี **Google Chrome หรือ Microsoft Edge** และ**สาย USB ที่ส่งข้อมูลได้** (สายชาร์จอย่างเดียวใช้ไม่ได้)

1. เสียบบอร์ดเข้าคอมด้วยสาย USB ช่องไหนก็ได้ (USB-C หรือ micro-USB)
2. เปิด **https://espressif.github.io/esptool-js/**
3. ตั้ง Baudrate เป็น `460800` แล้วกด **Connect** จากนั้นเลือกพอร์ตของบอร์ด (มักชื่อ `USB-SERIAL CH340` หรือ `CH340`)
   - ถ้าไม่มีพอร์ตให้เลือก: ลองเปลี่ยนสาย หรือลงไดรเวอร์ [CH340](https://www.wch-ic.com/downloads/CH341SER_EXE.html) แล้วถอดเสียบใหม่
   - ถ้าเชื่อมต่อไม่ได้: **กดปุ่ม BOOT ค้างไว้** (ปุ่มเล็ก 2 ปุ่มข้างชิป ESP32 ด้านหลังบอร์ด — ดูตัวอักษร BOOT กำกับ) แล้วกด Connect อีกครั้ง
4. ช่อง Flash Address ใส่ `0x0` แล้วเลือกไฟล์ **`docs/firmware/esp32-weather-full.bin`**
5. กด **Program** แล้วรอจนถึง 100% (ประมาณ 1–2 นาที)
6. กดปุ่ม **RST** บนบอร์ด 1 ครั้ง (หรือถอดสายแล้วเสียบใหม่)

### ถ้าสีบนจอเพี้ยน / จอขาวล้วน / ภาพกลับสี
จอของบอร์ดรุ่นนี้แต่ละล็อตใช้ชิปไม่เหมือนกัน ให้**แตะจอค้างไว้ 5 วินาที** แล้วบอร์ดจะเปลี่ยนโหมดจอและรีสตาร์ทเอง ทำซ้ำจนสีถูก (มี 6 โหมด)
สีที่ถูกต้องคือ **พื้นหลังสีน้ำเงินเข้ม และตัวหนังสือสีขาว** (ถ้าใช้ Serial Monitor อยู่ จะพิมพ์คำสั่ง `display` แทนก็ได้)

> อยากดูรายงานทาง Serial Monitor: ในเว็บ esptool-js ให้กด **Disconnect** แล้วไปที่ส่วน **Console** ตั้ง Baudrate เป็น `115200` แล้วกด **Start**

## ขั้นที่ 2 — ตั้งค่า Wi-Fi ด้วยโทรศัพท์

1. จอจะขึ้นหน้า "ตั้งค่า Wi-Fi ครั้งแรก" และไฟสีฟ้ากะพริบ
2. เปิด Wi-Fi ในโทรศัพท์ เชื่อมต่อชื่อ **`ESP32-Weather-Setup`** (ไม่มีรหัส)
3. หน้าตั้งค่าจะเด้งขึ้นเอง (ถ้าไม่เด้ง เปิดเบราว์เซอร์ไปที่ `http://192.168.4.1`)
4. เลือก Wi-Fi บ้าน → ใส่รหัสผ่าน → ใส่ชื่อเมือง (เช่น `Bangkok`, `Chiang Mai`, `ขอนแก่น`) → **บันทึก**
5. ให้โทรศัพท์กลับไปใช้ Wi-Fi บ้าน แล้วเปิด **http://esp32-weather.local**
   - ถ้าเปิดไม่ได้ (Android บางรุ่น) ให้ใช้เลข IP ที่แสดงใน Serial Monitor หรือดูในหน้าเราเตอร์

⚠️ ESP32 ใช้ได้เฉพาะ **Wi-Fi 2.4 GHz** เท่านั้น

หลังตั้งค่าแล้ว ถอดจากคอมไปเสียบที่ชาร์จมือถือ (5V) ได้เลย บอร์ดจะจำการตั้งค่าไว้

## การใช้งาน

| ต้องการ | วิธี |
|---|---|
| อัปเดตข้อมูลทันที | **แตะจอ 1 ครั้ง**, กด 🔄 บนหน้าเว็บ หรือพิมพ์ `now` |
| เปลี่ยนโหมดจอ (สีเพี้ยน) | **แตะจอค้าง 5 วินาที** หรือพิมพ์ `display` |
| เปลี่ยนเมือง | ช่อง "เปลี่ยนเมือง" บนหน้าเว็บ หรือพิมพ์ `city Chiang Mai` |
| เปลี่ยน Wi-Fi | ลิงก์ "ตั้งค่า Wi-Fi ใหม่" บนหน้าเว็บ, พิมพ์ `wifi` หรือ **กดปุ่ม BOOT ค้าง 3 วินาที** |
| ดูสถานะบอร์ด | พิมพ์ `status` |
| ข้อมูลแบบ JSON (สำหรับต่อยอด) | `http://esp32-weather.local/api/weather` |

## ไฟ LED สีบนบอร์ด
- 🔵 ฟ้ากะพริบ = โหมดตั้งค่า (รอใส่รหัส Wi-Fi)
- 🟡 เหลืองกะพริบ = กำลังเชื่อมต่อ Wi-Fi
- 🟢 เขียว = กำลังดึงข้อมูลอากาศ
- 🔴 แดงค้าง = ดึงข้อมูลไม่สำเร็จ (จะลองใหม่เองใน 30 วินาที)

## สำหรับนักพัฒนา (แก้โค้ดเอง)

| ไฟล์ | หน้าที่ |
|---|---|
| `esp32-weather.ino` | โปรแกรมหลัก, Wi-Fi, คำสั่ง Serial, รายงานทาง Serial |
| `display.h/.cpp` | จอ + ทัชสกรีน + LED RGB (ใช้ไลบรารี LovyanGFX) และหน้าจอทั้งหมด |
| `thai_text.h` | ข้อความไทยแบบรูปภาพ (สร้างจาก `tools/gen_thai_text.py` ห้ามแก้เอง) |
| `config.h` | **ค่าตั้งต่าง ๆ** — เมืองเริ่มต้น, รอบอัปเดต, ขา GPIO |
| `weather.h/.cpp` | ดึงข้อมูลจาก Open-Meteo, ค้นหาพิกัดเมือง, คำอธิบายภาษาไทย |
| `web.h/.cpp` | Web server: หน้าตั้งค่า Wi-Fi และแดชบอร์ด |
| `web_pages.h` | HTML/CSS ของหน้าเว็บ |
| `settings.h/.cpp` | บันทึกค่าลง Flash (Preferences) |

**Build ด้วย Arduino IDE 2.x**
1. Boards Manager → ติดตั้ง **esp32 by Espressif Systems** (3.3.x)
2. Library Manager → ติดตั้ง **ArduinoJson** (7.x) และ **LovyanGFX** (1.2.x)
3. เปิด `esp32-weather.ino` → Board: `ESP32 Dev Module` → Tools → Partition Scheme: **Huge APP (3MB No OTA)** → Upload

**แก้ข้อความไทยบนจอ:** แก้รายการ `TEXTS` ใน `tools/gen_thai_text.py` แล้วรัน `python3 tools/gen_thai_text.py` (ต้องมี Pillow)

**Build ด้วย arduino-cli**
```bash
arduino-cli compile -b esp32:esp32:esp32:PartitionScheme=huge_app --output-dir build/cyd .
```

### ไอเดียต่อยอด
- ใช้เซนเซอร์แสง (LDR ขา GPIO 34) ปรับความสว่างจออัตโนมัติ
- เล่นเสียงเตือนผ่านลำโพง (ช่อง SPEAK) เมื่อฝนกำลังจะตก
- เซนเซอร์ในห้อง (DHT22 / BME280) เทียบกับอากาศนอกบ้าน
- แจ้งเตือนฝนตก/ฝุ่น PM2.5 ผ่าน LINE หรือ Telegram
- พยากรณ์ล่วงหน้าหลายวัน, กราฟอุณหภูมิรายชั่วโมง
