# ESP32 Weather Monitor — notes for Claude

Arduino sketch for ESP32-2432S028 "Cheap Yellow Display" (ESP32 Arduino core 3.3.x, ArduinoJson 7.x, LovyanGFX 1.2.x). Users are beginners and speak Thai;
reply in Thai and keep user-facing strings (Serial, web UI) in Thai.

- Architecture: each module exposes begin()/loop(); loop() must never block for long.
- Shared state lives in esp32-weather.ino (`settings`, `weather`), declared in app.h.
- Weather source: Open-Meteo forecast + geocoding APIs over HTTPS (no API key).
- Two modes: setup portal (AP "ESP32-Weather-Setup" + captive DNS) and dashboard (STA + mDNS).
- Wi-Fi can also be provisioned over USB with Improv Serial (improv.cpp) from the web installer.
- Screen has 7 pages (tap cycles): today (big clock + Thai date + mini weather/market) / now / PM2.5 (with 12 h
  hourly PM forecast, Thai PCD levels) / forecast (12 h hourly temp+rain chart + 3 days) / sun & heat (heat index
  from apparent temperature with Thai DoH levels, UV now with WHO levels, burn time ~200/UV min, UV>=6 window) /
  Thai gold / SET. UI style: blue header bar, big numbers, cyan labels, yellow section titles, thin blue dividers.
- Market data (gold, SET, SET50, XAU, USD/THB) is collected by server/api/market.js, run by
  .github/workflows/market.yml every 10 min on weekdays, and published as market.json on the `market-data`
  branch; the board reads it from raw.githubusercontent.com (MARKET_DATA_URL). Gold: goldtraders.or.th blocks
  datacenter IPs (403), so Hua Seng Heng's API (association REF price) is used, then an estimate from world price.
  Rain alert when hourly precipitation probability in next 2 h >= RAIN_ALERT_PERCENT (beep on GPIO 26, not at night).
  Night dimming 22:00-06:00. Constants in config.h.
- Settings persist via Preferences namespace "weather" (ssid, pass, city, lat, lon).
- Release: web installer in docs/ (GitHub Pages, ESP Web Tools, https://wssnuk.github.io/esp32-weather/).
  After building, copy bootloader/partitions/app .bin (and merged image as esp32-weather-full.bin) into
  docs/firmware/ and bump "version" in docs/manifest.json. The sketch folder must be named esp32-weather to compile.
- Build: `arduino-cli compile -b esp32:esp32:esp32:PartitionScheme=huge_app` (app > 1.3MB).
- Colors: this panel batch renders mid-tone colors wrong, so the UI uses only pure colors (each channel 0 or 255)
  and Thai text is 1-bit (no anti-aliasing). Keep it that way.
- TFT has no Thai font: Thai strings are pre-rendered bitmaps in thai_text.h, generated by
  tools/gen_thai_text.py (Noto Sans Thai). Dynamic text (city, numbers) must be Latin; geocoding uses language=en.
- Display panel varies by batch: 6 modes (ILI9341 / ST7789 factory-init / ST7789 LovyanGFX-init, x invert),
  stored in Preferences "disp" (default 4); long-press touch 5 s or serial `display` cycles it. GPIO 2 is TFT DC — never use it as an LED.

## ESP32-S3 board (s3/esp32-weather-s3) — "Aurora Gold"
- Board: black "2.8" LCD Display ESP32-S3 240x320 Capacitive Touch" (Hosyond/LCDwiki-style). Display ILI9341-class
  on SPI: SCK12 MOSI11 MISO13 CS10 DC46 BL45, needs color inversion, rotation 5 (pure MV). Touch auto-detected
  on I2C (silkscreen says IO16=SDA, IO15=SCL). MISO reads 00 (not wired) — normal.
- Shares settings/weather/improv/web/market modules with the CYD sketch (copies in s3/esp32-weather-s3).
- Graphics are generated by s3/tools/gen_assets.py (JPEG backgrounds, PNG gold digits/icons, VLW fonts, 4-bit Thai).
- Build: ARDUINO_DIRECTORIES_USER=/root/Arduino-s3 (LovyanGFX 1.2.36; 1.2.7 fails on core 3.3.x) and
  `-b esp32:esp32:esp32s3:CDCOnBoot=cdc,PSRAM=opi,FlashSize=4M,PartitionScheme=no_fs` (2 MB app x2 for OTA).
- Release: docs/s3w/ with versioned file names (avoid browser cache), manifest.json and version.json.
  Boards poll version.json every 6 h and self-update (autoupdate.cpp). Bump APP_VERSION and version.json together.
- Display "presets" (1.3.0+): 4 panel init lists in display.cpp (0 old minimal, 1 ILI9341V IPS vendor, 2 ILI9341
  full gamma, 3 ST7789). Stored in Preferences "s3ui" (preset/pdone/ptries). First boot runs a tap-to-choose loop;
  ILI9341 B6 (display function) 2nd byte must stay 0x82: 0xA2 mirrors, 0xC2 flips upside down.
  long-press 5 s or serial `preset` re-runs it (then a 2nd step picks the "vivid" level).
- Vivid (1.3.1+): 64K-entry RGB565 LUT in PSRAM (saturation + gamma) applied to the canvas in endFrame (saturation, contrast, gamma>1 = deeper image; user asked for "เข้ม");
  levels 0-3, Preferences "s3ui" key "vivid", serial `vivid N`. Default VIVID_DEFAULT=2. Rotation is only changed via serial `display`.
- Radar page: radar.cpp downloads radar.json + f0..f3.jpg (224x204) from the market-data branch in a FreeRTOS task
  (double-buffered). Map is centred on Bangkok (server/radar.py); page shows a coverage note for cities > 25 km away.
- Sound: sound.cpp, ES8311 codec at I2C 0x18 on the touch bus (lgfx i2c port 1), I2S MCLK4 BCLK5 WS7, DOUT 6 or 8,
  PA enable GPIO1 (level tested). One-time tap test picks the config (Preferences "s3snd"). Chimes are synthesized
  original tones only — never bundle copyrighted music.
