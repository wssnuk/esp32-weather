## ไฟล์ที่ใช้พิมพ์

| ไฟล์ | ชิ้นส่วน | ขนาดชิ้นงาน | วิธีวางพิมพ์ |
|---|---|---|---|
| `front_bezel.stl` | ฝาหน้า (มีหน้าต่างจอ + เสาสกรู) | 54.6 × 90.6 × 9.5 | คว่ำหน้าลงบนฐาน ไม่ต้องใช้ซัพพอร์ต |
| `back_cover.stl` | ฝาหลัง (ตะแกรงลำโพง, รูกดปุ่ม, ช่องระบายอากาศ) | 54.6 × 90.6 × 14.0 | วางด้านนอกลงฐาน ไม่ต้องใช้ซัพพอร์ต |
| `desk_stand.stl` | ขาตั้งโต๊ะเอน 20° | 64 × 50 × 34 | วางด้านฐานลง |

ขนาดกรอบประกอบแล้ว: **54.6 × 90.6 × 21.5 มม.** (เผื่อช่องด้านหลัง 12 มม. สำหรับสายและลำโพงเล็ก)

**ตั้งค่าพิมพ์แนะนำ:** PLA หรือ PETG, หัว 0.4 มม., ความสูงชั้น 0.2 มม., ผนัง 3 เส้น, เติมเนื้อ 20%
ถ้าใช้ PETG/ABS ที่หดตัวต่างกัน ปรับ `CLR` (ระยะเผื่อรอบบอร์ด, ค่าเริ่ม 0.3 มม.) ในสคริปต์

## การประกอบ

1. วางบอร์ดคว่ำจอลงในฝาหน้า ให้รูยึด 4 มุมตรงเสา และ USB-C ตรงช่อง
2. เดินสายลำโพงในช่องด้านหลัง (ลำโพงวางตรงตะแกรงกลางฝาหลัง ติดด้วยเทปกาวสองหน้า)
3. ปิดฝาหลัง แล้วขัน **สกรู M3 ยาว 20 มม. 4 ตัว** จากด้านหลัง ทะลุ PCB เข้าเสาฝาหน้า (เสามีรูนำ Ø2.5 สำหรับสกรูเกลียวปล่อย)
   ขันพอแน่น อย่าแรงเกิน เพราะจะกดทับจอ
4. กดปุ่ม BOOT / RESET ผ่านรูเล็กที่ฝาหลังด้วยไม้จิ้มฟันหรือปลายคลิปหนีบกระดาษ

## แก้ขนาดเอง

```bash
pip install manifold3d trimesh
```

```bash
python3 build_case.py
```

ค่าที่ปรับได้อยู่ต้นไฟล์ `build_case.py`: `CLR` (ระยะเผื่อ), `WALL` (ความหนาผนัง), `BACK_DEPTH` (ความลึกด้านหลัง), ตำแหน่ง `USB_X`, `BTN`, `SD_Y0/SD_Y1`

> ตำแหน่ง USB-C, ปุ่ม และช่อง SD คำนวณจากภาพแบบของผู้ผลิต อาจคลาดเคลื่อน ±1 มม. ช่องจึงเผื่อกว้างไว้แล้ว
> แนะนำให้วัดบอร์ดจริงด้วยเวอร์เนียก่อนพิมพ์ หรือพิมพ์ฝาหน้าทดลองก่อน (ใช้เวลาน้อยกว่า)
